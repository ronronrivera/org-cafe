# Organization Café

A centralized, web-based directory, activity showcase, and announcement platform for recognized student organizations in **Caraga State University (CSU)**.

Organization Café replaces fragmented discovery methods (scattered Facebook pages, physical posters, word-of-mouth) with a single responsive platform where students and visitors can browse organizations, search by name or category, view custom organization pages, check LCO fee-clearance status, and access announcements and upcoming events in real time.

## Features

- **Public Organization Directory** — Browse, search (by name or keyword), and filter all recognized CSU organizations by category, grouped into category sections on the landing page. No login required.
- **Organization Profile & Activity Showcase** — Each organization has a dedicated public page with its logo, description, category, official Facebook link, chronological feed of posts and events, media, and pinned announcements.
- **Join Button** — Links to each organization's Google Form, active only between the open/close dates configured by the organization.
- **LCO Fee Clearance Lookup** — Students can verify their fee-clearance status by entering a single student ID (returns only "Paid"/"Not Paid", protecting data privacy). Administrators can view the full dataset and filter by department, course, and year level, and import records from the LCO-provided Excel file.
- **Organization Manager Dashboard** — Authenticated org_rep workspace scoped to a single organization for managing profiles, posts, events, media, page layout, and announcements.
- **Admin Control Hub** — LCO/OSAS administrators onboard organizations and categories and issue org_rep credentials. Admin accounts are provisioned externally; there is no public self-registration.
